# Python Day 121 - Delete List Element

This program demonstrates how to delete an element from a Python list using the `del` keyword.

## Code

The program creates a list of numbers and deletes the element at index `2`.

## Example

Original list:

```text
[10, 20, 30, 40, 50]
```

After deleting the element at index 2:

```text
[10, 20, 40, 50]
```

## Concepts Used

* Python Lists
* List Indexing
* `del` keyword
* `print()` function

## What I Learned

I learned how to delete a specific element from a Python list using its index with the `del` keyword.
